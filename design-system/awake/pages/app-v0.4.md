# Awake v0.4 应用视觉覆盖

本文件覆盖旧 MASTER 中面向营销展示的页面模式、紫蓝配色、字体推荐。当前目标是长时间使用的 macOS 听歌软件。

- 石墨绿背景 `#191b19`，侧栏和播放器 `#151815`，内容表面 `#202320`。
- 暖麦色主操作 `#d9ba87`，文字 `#eeeae4`，次级 `#a5aaa0`，弱文字 `#7f877c`。
- 设备和本地状态用低饱和绿；不把技术规格、模型字样和营销徽章当成视觉主角。
- 系统中文无衬线为正文；宋体只用于主视觉的一部分标题；SF Mono 用于时间和技术参数。
- 页面结构是固定侧栏、安静顶栏、可滚动内容、稳定底部播放条。播放不随页面切换中断。
- 首屏核心动作是开始聆听；空曲库核心动作是添加自己的音乐。
- 封面优先使用真实曲库图像；缺图时使用抽象占位，不虚构艺人或曲目。
- 推荐显示真实原因；未接入的云端模型与音乐生成服务明确标为未连接。
- 375px 下保留图标导航和播放控制，EQ 频段允许面板内横向滚动；文档本身不横向溢出。
- 遵守 reduced-motion；按钮与范围输入有名称和焦点样式；弹层可 Escape 关闭并限制 Tab 焦点范围。

# Awake 0.9.41

macOS 14+（仅 Apple Silicon，ad-hoc 签名）。这一版是**界面改造**：播放页重做、设置与源导入重排、
调音 agent 加了模式，并第一次把间距 / 圆角 / 字号 / 组件收成一套设计系统。

## 为什么是这一版

前几版一直在补功能，界面是「一页页长出来的」：17 种字号、11 种圆角、20 种间距、
164 段解释用小字、首页四个入口和底部 tab 重复、播放页把设置项平铺成一张长表。
这一版按「先建规则，再改页面」处理。

## 做了什么

**播放页（重做）**

- 首屏只留：封面 → 曲名 → 歌词 → 进度 → 传输；EQ、信号链、声音摘要全部收进「声音与仪器」。
- 播放效果：封面取色的环境光 9 秒呼吸、封面 12 秒微呼吸，暂停即停；减弱动效时全静止。
- 歌词随动：五行窗口，当前行固定居中、加粗，换行 260ms；点任意行跳转；没有歌词时给「添加歌词」。
  解析结果按文本哈希缓存，播放页每秒重算多次 body 也不会重复跑正则。
- 顶部条从实色条改成底色渐隐；工具键补齐 44pt。

**设置 / 源导入**

- 顶部状态摘要卡：版本、曲目 / 歌单 / 来源 / 缓存（现算）、AI 是否已配置。
- 入口统一「图标 + 标题 + 一句说明 + 真实状态」；来源的刷新 / 移除收进 44pt 菜单；
  两个维护分区合并；六段长说明改成可折叠的「说明」。
- 添加音乐改成来源中心：已连接列表 + 三种服务器各一行（写清需要准备什么）+ 本机导入；
  点哪一行就带着类型进编辑器，不用再选一次。

**agent 模式**

- 调音 agent 五种模式：均衡 / 人声 / 耐听暖声 / 现场感 / 夜间低音量。
  每个模式同时决定 AI 约束与**本地规则动作**——没配 AI 时也有真实差别，且结果标明「本地规则 · 模式名」。
- 安全阀不变：单段 ≤6 dB、最多 6 段、不抬整体响度。
- 听歌搭子新增四种策展模式（此刻 / 通勤 / 专注 / 深夜），只改发给 AI 的意图；
  本地排序仍按收藏与收听，界面明说「本地排序不区分场景」。

**设计系统与全局收敛**

- 新增 `DesignSystem.swift`：间距只用 4 的倍数、圆角三档、动效两档、结构线 0.5pt、点击目标 44pt，
  以及 `AwakeSectionTitle / AwakeRow / AwakeNote / AwakeCard / AwakeEmptyState / 按钮`。
- 首页删掉与 tab 重复的入口，空态只给一个主行动；曲库的来源筛选从菜单改成一排 chip；
  长说明批量改为折叠（共 34 段）；写死的字号从 44 处收敛到 7 处。
- 桌面：删掉侧栏顶部不可点的 `awake.` 字样，页面身份交给顶栏面包屑；新增 `⌘1–⌘6` 切分区。
- iOS：删掉设置页摘要卡上的品牌名；新增横滑换 tab，规则抽成纯函数
  （方向、80pt 阈值、2:1 比例、边缘 24pt 留给返回手势、横向控件豁免、到头不循环）。

## 验证

- `swiftc -typecheck`（iPhoneSimulator SDK 27.0）→ 0 error。
- `xcodebuild build-for-testing` → **TEST BUILD SUCCEEDED**（含新增的歌词定位、调音模式用例）。
- 纯逻辑 harness：`bash Tools/run_library_import_harness.sh` → **35 项断言 / 0 失败**
  （导入判重 26 项 + 横滑翻页规则 9 项）。
- Rust：`cargo test -p awake-core -p awake-app --lib` → 57 / 123 通过，0 失败。
- 前端：`npm test --prefix ui` → 57 通过；`npm run build --prefix ui` → exit 0。
- 模拟器实截（深色皮肤）：首页 / 曲库 / 设置 / 添加音乐 / 声音 / 评测 / 播放页 / 调音模式，
  见 `docs/ios-screenshots/*-0.9.41.png`。

## 已知边界

- **真机手势没点过**：模拟器不能注入触摸，横滑换 tab、歌词点击、滑杆拖动都只验到规则与编译。
  XCTest 在本机仍跑不起来（没有 `Simulator.app`，`test-without-building` 停在起 test host）。
- iOS 原生 `TabView` 没有跟手分页；按用户决定保持「横滑触发切换 + 淡入」，不换原生 tab bar。
- 玻璃 / 白色皮肤只抽查了设置页，其余页面只截了深色皮肤。
- 书库、播放列表导入、设备、插件、曲目曲线只做了说明折叠与字号收口，页面骨架未重排。

## 升级

- 覆盖安装即可，无数据迁移。首次启动会按 0.9.40 的规则整理一次曲库（已整理过则不再重复）。
- 桌面与 iOS 版本号一致；两端皮肤 token 不变。

## 构建来源与 CI 状态（发布时写清）

- **附件由本机构建**：macOS 包用 `Tools/build_rust_app.sh`（AWAKE_ARCHS=arm64），
  IPA 用 `Tools/build_ios_app.sh`（unsigned）。两者的 `.sha256` 随附件提供；
  `codesign --verify --deep --strict` 通过，`shasum -a 256 -c` 通过。
- **CI 没有跑成功**：GitHub Actions 的 macOS runner 两次排队 15 分钟后被取消
  （`run 45421987772`，macos job 从未启动、`started_at` 为空），`publish` 作业因此被跳过。
  所以 Release 里**没有 CI 产物**，4 个附件都是本机上传的。
- 这不是编译失败：同一份代码在本机完成了 `build-for-testing`、Rust/前端测试与两端打包。
- runner 恢复后可以重跑；CI 产物会以同名附件覆盖（`gh release upload --clobber`）。

# Awake 0.9.3

macOS 14+，仅 Apple Silicon（arm64）构建（ad-hoc 签名），不支持 Intel Mac，首次打开可能需要在「隐私与安全性」中允许。这一轮只做一件事：**把「加进来的东西去哪了」补上**——Plex 授权不再每次重来，来源里的曲目有地方看，本地文件夹在连接前就能验证。

## 这次修正

- **Plex 登录会记住**。上一版的 PIN 授权结果只活在内存里：关一次应用、或者装一个新构建，就得重新打开浏览器授权一次。现在授权拿到的 Token 写进凭据存储，服务器与所选音乐库写进 `plex-account.json`；下次启动自动用记住的 Token 列出服务器，回到上次那台服务器、那个音乐库，不用再点「用 Plex 账号登录」。授权被 Plex 端撤销时，界面会直说「上次的 Plex 登录已失效」，而不是静默空白。
- **凭据不再只放钥匙串**。macOS 把钥匙串条目的访问权限绑在访问者的代码签名上；本应用是 `codesign --sign -` 的 ad-hoc 签名，**每次重新构建 cdhash 都会变**，于是上一版写进去的 Token 与密码对新版本就是「别人的条目」。这是「每次安装后之前的登录丢失」的根因。现在真正的存储是数据目录里的 `credentials.json`（权限 0600），钥匙串只作为镜像；从钥匙串读到的旧值会自动迁移进文件。已有的来源密码会在第一次读取时自动完成迁移，不需要重新连来源。
- **加进来的内容有地方看了**。音乐来源页每个来源都多了「查看曲目」，点进去就是曲库、并且只显示这个来源；曲库页顶部多了按来源筛选的按钮；来源卡片下面新增「最近添加」，按加入时间排序，刚连上的来源排最前。连接成功后会自动跳到曲库并选中新来源，不再是只弹一句「已连接」。
- **来源可以移除了**。之前只能加不能删；现在每个来源有「移除来源」（点两次确认），曲目、来源记录、凭据一起清掉。
- **本地文件夹在连接前就验证**。选择文件夹后立刻用新增的 `probe_music_path` 检查：路径会先归一化（去引号、还原 `file://`、展开 `~`、去掉末尾斜杠），然后数一数里面有多少音频文件并把前几个文件名显示出来。文件夹空、格式不支持、系统拒绝读取（TCC）都会当场说清楚，而不是扫完给 0 首让人反复重试。
- **路径归一化覆盖所有本地入口**：选择文件夹、选择音频文件、拖进窗口、手输路径，走的是同一套归一化。

## 数据与兼容

- 新文件：`~/Library/Application Support/com.seven.awake/credentials.json`（0600）与 `plex-account.json`（不含 Token）。
- `library.json` 结构未变，旧曲库直接可用；已连接的来源不需要重连。
- 升级后第一次打开，旧的钥匙串凭据会被读取并迁移；如果系统弹钥匙串授权框且被拒绝，重新连接一次该来源即可。

## 验证

- Rust：`cargo test -p awake-app` — **105 通过 / 0 失败 / 10 按需忽略**（新增 8 条：凭据跨重启可读、凭据文件 0600、损坏文件不连坐、Plex 账号跨重启、Token 不写进元数据文件、路径形态归一化、目录/单文件/空目录/不存在四种探测结果、Plex 账号拒绝坏 Token）。
- 前端：`npm test --prefix ui` — **25 通过 / 0 失败**（新增 8 条：来源收窄、专辑收窄、最近添加排序、来源状态行、筛选条与连接后选中、Plex 账号文案、重启后服务器定位、重启后音乐库定位）。
- 构建：`npm run build --prefix ui` 通过 `vue-tsc`；arm64 release 构建 21m19s 产出 `Awake-0.9.3-macos-arm64.zip`（9.3 MB），`codesign --verify --deep --strict` 通过；独立 HOME 启动冒烟，日志 `FRONTEND_READY version=0.9.3`；本机 `/Applications/Awake.app` 已更新到 0.9.3 并启动验证。
- 未完成：x86_64 侧构建时本机负载 200+（DSH 渲染进程与 diskimagesiod 占满 CPU），已停掉。通用包需要机器空闲时重跑 `AWAKE_ARCHS="arm64 x86_64" bash Tools/build_rust_app.sh`。
- 未验证：真实 Plex 账号的一次完整授权（需要账号与服务器）；重装后钥匙串迁移只走了单元测试，没有在真机上重复安装验证。

## 已发布产物（GitHub Release v0.9.3，Latest）

## 更正（2026-11-17）

- 原文开头写「Apple Silicon / Intel 通用构建」。这句话与实际发布的产物不符：本轮只打出了 arm64 包，x86_64 构建因本机负载过高被停掉（见上方「未完成」一条），GitHub Release 里也只有 `Awake-0.9.3-macos-arm64.zip` 一个可执行包。已在开头改为「仅 Apple Silicon（arm64）」，此处保留原文记录，避免读者被误导后下载到不存在的 Intel 包。

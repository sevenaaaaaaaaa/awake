# Awake 0.9.1

macOS 14+，Apple Silicon 构建（ad-hoc 签名），首次打开可能需要在「隐私与安全性」中允许。这一轮是修缺，不动功能面。

## 本次重点

- **Plex「连接曲库」修好了。** 之前选完服务器点连接，程序看起来在工作，结果一首歌都没进来。原因是 `applyPlexServer()` 只填了地址、Token 和名称，**没把来源类型换成 Plex**——于是「连接曲库」走的是本地文件夹扫描那条分支，把 `https://…` 当目录递归扫了一遍。现在选服务器时一并把类型、地址、Token、名称写全。
- **音乐生成也用上预置平台了。** 「AI 音乐创作」的服务表单里多了与「听歌搭子」同款的预置下拉，选一个平台就把地址和模型填好，只剩 token 需要粘。下拉只列音乐生成可用的平台。
- **深夜档按你的时区算。** 这个成就原来用 UTC 取模判断 0–5 点，非 UTC 时区的人看到的数字是错的。现在按本机时区取小时。

## 验证

- Rust：`cargo test -p awake-app --lib` — **97 通过 / 0 失败 / 10 按需忽略**，新增深夜档本地时区用例。
- 前端：`npm run build --prefix ui` 通过 `vue-tsc` 类型检查，产物 298.08 kB（gzip 102.76 kB）。
- **未验证**：Plex 真实账号的端到端（需要你自己的服务器地址与 Token）；真机点击回归。

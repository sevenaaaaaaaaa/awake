# Awake 0.9.1

macOS 14+，Apple Silicon / Intel 通用构建（ad-hoc 签名），首次打开可能需要在「隐私与安全性」中允许。这一轮是 0.9.0 的收尾与修正，没有新增界面模块。

## 本次修正

- **Plex 连接走对分支**。上一版用 Plex 账号登录后，服务器地址与 Token 会被填好，但「连接曲库」仍然走本地文件夹扫描，把 `http://…` 当路径去扫，结果一首也扫不出来。原因是填入服务器信息时没有把来源类型切到 Plex。现在选完服务器，来源类型会自动变成 Plex，连接时直接调 Plex 接口。
- **深夜档按本地时间算**。成就里的「深夜档」原本用 UTC 小时判断 0–5 点，东八区用户下午听到的歌会被算成深夜。现在按系统本地时区计算。
- **音乐生成服务有预置平台了**。0.9.0 只给策展（选歌）做了预置下拉，音乐生成侧要自己抄地址。这一版把同样的下拉补上，选中即填好地址与模型，只剩 token 需要粘。

## 新增依赖

- `chrono`（只开 `clock` 特性）用于取本地时区。构建体积影响可忽略。

## 验证

- Rust：`cargo test -p awake-app --lib` — **97 通过 / 0 失败 / 10 按需忽略**。
- 前端：`npm run build --prefix ui` 通过 `vue-tsc` 类型检查，产物 298.08 kB（gzip 102.76 kB）。
- 构建：`Tools/build_rust_app.sh` 产出 `dist-rust/Awake.app`（arm64 + x86_64），`codesign --verify --deep --strict` 通过。
- 未验证：Plex 真实账号的连接过程（需要用户提供账号与服务器）；深夜档跨时区只做了单元测试，没有在真实收听数据上跑过。

## 与 iOS 的配合

iOS 0.9.1 与桌面 0.9.1 版本号对齐，但这一版**手机端没有功能变化**——本轮改动全在桌面的 Rust 与前端。0.9.0 的接力协议 v2 保持不变，两端可以各自独立升级。

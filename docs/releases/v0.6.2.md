# Awake 0.6.2

macOS 14+（Apple 芯片）本地播放器，Rust / Tauri 2 / Vue 3 主线。本页为 GitHub Releases 的桌面版说明；安装包为 ad-hoc 签名，首次打开可能需要在“隐私与安全性”中允许。

## 0.6.2 · 整理封面、歌词与乐评

- 曲目行资料按钮或右键进入整理：读取内嵌与相邻封面、歌词，可手动导入图片和评论 JSON。
- 在线候选来自 MusicBrainz、Cover Art Archive、LRCLIB、CritiqueBrainz 的公开 API，用户主动查询，不上传音频与来源凭据。
- 单曲与专辑乐评分开展示，保留署名、原链接与许可；缺失时不生成虚构评论。
- 名称整理会清理音质标记并保留 Live / Remix 版本信息；文件名仅作建议，不重命名或回写原文件。
- 没有专辑信息的录音不再共用其他文件的封面；缺少图片时显示按标题生成的抽象配图。
- 编辑可恢复，重新扫描保留确认过的资料。

## 0.6.1 · Telegram 个人媒体库

- 新增 Telegram 个人媒体库来源，通过用户自托管连接器选择收藏夹、指定频道或聊天文件夹中的频道。
- 支持 JSON/XML/TXT 个人连接配置导入，令牌另存系统钥匙串。
- 桌面使用 HTTP Range 流式读取，复用现有解码、队列与 EQ 链路。
- 只读取显式选择的最近消息范围，不提供公共目录；Telegram 曲目元数据不进入云端 AI 请求。
- 连接器部署与配置格式见 `Tools/telegram_connector/README.md`。

## 验证

- 54 项 Rust 测试通过（另有 5 项真实声卡 / 长音轨测试按需单独运行）；Vue / TypeScript 生产构建通过。
- 桌面安装包由 `Tools/build_rust_app.sh` 构建并 ad-hoc 签名，`codesign --verify --deep --strict` 通过。
- 界面检查使用浏览器预览与本地夹具，未替代真实用户账号验收。

## 限制

- 未做主观听感评测、真实 NAS/Plex 产品适配和真实 Telegram 账号验收。
- 在线资料匹配依赖第三方公开服务可用性；本次联调 MusicBrainz 返回 503。
- 不重命名磁盘文件、不回写音频标签；不提供公共音乐源目录或分享入口。

Assets 同时提供 `SHA256SUMS`，可使用 `shasum -a 256 -c SHA256SUMS` 校验。

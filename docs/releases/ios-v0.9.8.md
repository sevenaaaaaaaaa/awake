# Awake iOS 0.9.8

iOS 17+。这一版只动一件事：**「正在播放」重做。**

原来的播放页是一个任何音乐 App 都有的页面——紫蓝渐变封面占掉三分之一屏，中间一个 `✨ EQ 增强已就绪` 的发光胶囊，下面两排四个按钮，底部一个 `Speaker` 裸英文，右上角一个系统样式的「完成」胶囊。产品最值钱的东西（这条链路现在在做什么）全被藏起来了。

## 1. 换成仪器面板

按声学仪器的排法重排，尺寸全落在 4pt 网格上，字重只有 400/500，颜色只用一个中性阶加一个强调色：

- **链路条**：`音源 · 解码 · EQ · 输出` 四段，每段写真实数值——`WAV` / `48 kHz` / `28 段` / `本机扬声器`。路由名做了本地化，`Speaker` 不会再出现。
- **31 段曲线**：这台设备当前实际生效的增益，对数频率轴、0 dB 基线、31.5 / 125 / 500 / 2k / 8k / 16k 刻度、最高调整点标注（如 `20kHz −3.6 dB`）。
- **曲线能拖**：按住曲线上下拖直接改那一段，松手写回听感链路（`setChainGains`）。这是播放页里唯一新增的交互，改的是真的 EQ，不是动画。
- **静默封面**：没有封面图时用中性面 + 顶部刻度，不再有渐变球、光斑和 `PERSONAL SOUND ARCHIVE` 标语。
- **一个主操作**：播放键是页面里唯一的实心按钮。刷音乐降到图标，接力 / 接收接力 / 整理封面歌词收进「更多」。
- **同专辑曲目**：直接列在下方，可点播，填住了原来那片空白。

## 2. 没有听感链路时不画空线

没有链路时原来会画一条平的曲线，看起来像坏了。现在换成一段说明加一个入口：**「还没有听感链路 · 当前输出按平直曲线播放」→ 去「声音」建立链路**，点一下直接切到声音页。

## 3. 换掉右上角的「完成」

那个胶囊是系统 toolbar 的默认样式，和仪器面板不搭，还占着右上角。现在整个导航栏隐藏，改成自绘的顶部条：左上角一个下拉箭头，中间一行「正在播放」。同时「正在播放」从 sheet 改成全屏呈现——sheet 的顶部圆角和系统背景色会在页面上留下一块比正文更亮的区域。

## 4. 仍未闭合

- 桌面端的 stage 页还是原来的样子，同一套规则没套过去。
- 首页与侧栏还有 `YOUR LISTENING SPACE` 这类大写宽字距标签，以及渐变封面。
- 曲线只能拖单段，还不能多选频段或存成预设。

# 0.9.45

> 版本号 0.9.45（桌面与 iOS 同一号），iOS build 57。
> 这一版不加任何功能：把 0.9.44「只有黑与白」迁移漏掉的组件级旧配色扫干净，
> 顺手统一几处交互细节。雪豹式的一轮——磨掉的是颜色债，不是加东西。

## 背景：黑白迁移只改了一半

0.9.44 把令牌层（`:root`）换成了黑白 Obsidian（"桌面端此前是暖绿/沙色，两端放在一起像两个产品"），
但几十处**组件级样式**还写着旧配色的字面值：收藏爱心是金色（`#d9ba87`）、滚动条是鼠尾草绿
（`#c4cbb4`）、错误提示边框是绿、来源图标底是绿、代理输入框带绿渐变、推荐卡角光是沙金。
其中一部分已被 `themes.css` 的令牌规则覆盖成了死代码，另一部分真漏在界面上。
这一版全部清掉：铬件一律令牌化（`var(--text/--muted/--line/--tint/--accent)` 或 `color-mix`），
不再有游离在系统外的字面色。

## 你能看到的

- **颜色归位**：金色爱心、绿色滚动条、绿边错误提示（改语义 danger 红）、绿底来源图标、
  沙金推荐卡角光、灵感工作室金边、代理输入框绿渐变、音量/EQ 滑块米色拇指、
  首页三张心情卡（专注/探索/最爱）的绿盘与沙色环——全部中性化；
- **保留的彩色是内容**：缺封面录音的抽象配图（赭石/森林/陶土/蓝四风格与轨道、地平线、太阳）、
  黑胶拟物的盘面纹理与米色唱片标——它们代表音乐，不代表界面；
- **按下有反馈**：所有按钮按下时透明度短暂降到 0.85（此前按下无任何视觉回应）；
- **选区不再是系统蓝**：文字选中底色改为强调色、文字反色（`::selection`）；
- **一致性**：胶囊圆角统一 `999px`（此前 `100px`/`999px` 混用）、过渡时长统一 `180ms/120ms`
  （此前 `0.18s/180ms/0.2s` 混写）、最小字号从 6px 提到 7px（mono 眉标与紧凑 EQ 刻度）、
  `themes.css` 两组重复的 `border-color` 规则合并、文件尾部压缩的媒体查询展开为正常格式。

## 实现

- `ui/src/styles.css`：54 组字面色替换为令牌/`color-mix`，新增 `::selection` 与 `:active` 反馈，
  圆角/时长/字号统一；
- `ui/src/themes.css`：border-color 组去重（并集一块）、`.hero-actions .button` 圆角对齐、
  尾部 `@media` 块格式化；
- `ui/src/MediaInspector.vue`：`z-index:120` 补空格（格式）。

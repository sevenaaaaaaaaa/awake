# Awake 0.6.3

macOS 14+（Apple 芯片）本地播放器，Rust / Tauri 2 / Vue 3 主线。本页为 GitHub Releases 的桌面版说明；安装包为 ad-hoc 签名，首次打开可能需要在“隐私与安全性”中允许。

## 来源连接修复

- WebDAV 跟随同源 301/302/307/308 重定向（最多 3 跳），跨站重定向直接拒绝，避免凭据外泄。
- 支持 Digest 认证：`qop=auth` 与无 qop、MD5 / SHA-256，使用服务器挑战中的 realm / nonce / opaque，并复用挑战避免每个 Range 请求先吃一次 401。
- 新增按来源的“允许自签名 HTTPS 证书”开关（默认关闭），只作用于该来源的请求。
- 错误信息带状态码、地址与中文提示：401（账号 / 应用密码）、403（目录权限）、404（路径，如缺少 /dav）、405（未开启 WebDAV）、返回 HTML（地址指向登录页或普通网站）。
- 单个子目录 403 / 404 会跳过并继续扫描；根目录失败仍整体报错，不产生“静默空库”。

## Plex 账号登录

- 新增“用 Plex 账号登录”：创建 PIN 后在浏览器完成 Plex 授权，自动获取服务器列表与音乐库。
- 选中服务器与音乐库后填入地址与 Token，仍保存到系统钥匙串；手动填写 Token 保留为兜底。
- Token 只放在请求头，不拼进 URL 或错误信息。

## 验证

- Rust：`awake-app` 31 passed / 5 ignored，`awake-core` 37 passed；覆盖 Digest RFC 向量与计数器、同源重定向、HTML 识别、mock 服务器下的重定向跟随与跨源拒绝、403 子目录跳过、Plex resources / sections 解析、旧曲库兼容。
- 前端：`npm run build --prefix ui`（vue-tsc + vite）通过。
- 桌面安装包由 `Tools/build_rust_app.sh` 构建并 ad-hoc 签名。

## 限制

- 未连接真实 NAS 验证 Digest / 自签名 / 重定向组合；未使用真实 Plex 账号完成服务器发现与扫描。
- 不内置 SMB 客户端，NAS 请用系统挂载或 WebDAV。
- 不重命名磁盘文件、不回写音频标签。

Assets 同时提供 `SHA256SUMS`，可使用 `shasum -a 256 -c SHA256SUMS` 校验。

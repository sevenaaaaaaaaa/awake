# Awake 0.8.1

macOS 14+，**通用安装包（Apple Silicon + Intel）**，ad-hoc 签名，首次打开可能需要在“隐私与安全性”中允许。

## 本次重点

- **安装包改为通用二进制**：同一个 Awake.app 同时包含 arm64 与 x86_64，Intel Mac 不需要另找版本。构建脚本默认执行双架构编译并用 lipo 合并，随后对两个架构逐一校验。
- **修复 0.8.0 书架遗漏**：没有专辑标签的有声书按文件夹归并；应用自己生成的有声书 / 广播剧（单层文件、章节较短）按来源归并，标题取「有声书 · 书名」并去掉任务 UUID 前缀。用真实 library.json 复核：生成书籍「未命名有声书」2 章可以出现在书架。
- 其余功能与 0.8.0 相同：Plex 多线路与分区、本地文件夹 / 文件导入、歌单待匹配条目、听书与续听、AI 拆书 / 拆剧、新闻 / 邮件播报、本周总结、固定的「为你生成」歌单。

## 验证

- Rust：awake-core 42 项、awake-app 73 项通过（10 项真实声卡 / 长音轨测试按需忽略），0 失败。
- 构建：awake-app 同时编译 `aarch64-apple-darwin` 与 `x86_64-apple-darwin`，lipo 合并为通用二进制；`lipo -info` 显示 `x86_64 arm64`；`codesign --verify --deep --strict` 通过。
- 启动：arm64 直接启动并写入 `frontend_ready version=0.8.1`；x86_64 切片在 Rosetta 下用独立 HOME 启动，同样写入 `frontend_ready version=0.8.1`。
- 详见[验证记录](../validation-v0.8.1.log)。

## 未验证

- 真实 Intel Mac 硬件上的原生启动、音频设备与长时间播放（本机以 Rosetta 运行 x86_64 切片验证启动链路，不等同于 Intel 原生声卡验收）。
- 真实 Plex 账号与服务器、复杂 MIME 邮件、两小时以上长篇合成耗时。
- iOS 仍为独立版本（0.7.8），本轮新功能是桌面端先行，尚未移植到 iOS。

# Awake 0.9.8

macOS 14+（本轮仅 Apple Silicon，ad-hoc 签名）与 iOS 17+（未签名 IPA）一起发。桌面与 iOS 在这一版第一次对齐到同一套界面口径：**「正在播放」不再是一个放封面和胶囊的页面，而是一块仪器面板；均衡曲线不再是只读图，而是可以直接拖的东西。**

这一版没有新功能。把已有的能力（31 段 EQ、听感链路、真实解码参数）从「看不见、要一根根滑块调」变成「看得见、能上手」。

## 1. 桌面「正在播放」：仪器面板

原来的 stage 页是「大封面 + 标题 + 一句永远不动的 `HERE. NOW. NOTHING ELSE.`」，歌词空着时用一个大图标和两行文案占位。产品的独有价值——这条链路此刻在做什么——全在别处。

现在按声学仪器排：

- **链路条**：`音源 · EQ · 输出` 三段，每段写这一首的真实值，例如 `FLAC / 24 bit / 96 kHz · 2 声道` / `31 段` / `本机输出`。没有链路时 EQ 段写「平直」，不假装有处理。
- **31 段曲线**：对数频率轴，0 dB 基线、±6 dB 虚线、`31.5 / 125 / 500 / 2k / 8k / 16k` 刻度，峰值那一段标出频点与增益（如 `20kHz −3.6 dB`）；曲线下方有面积填充，形状一眼可读。
- **平直时给一句话，不画空网格**：没有链路就写「当前输出按平直曲线播放 · 在「声音」里选择耳机与链路后这里会画出实际曲线」，避免一条平线看起来像坏了。
- **事实清单**：格式、时长、来源、加入时间。都在曲目里现成，只是以前没摆出来。
- **歌词面板**：单独一栏，没有同步歌词时是一行说明，不再是占掉半屏的空状态。
- **保留曲目频谱画像**，位置移到歌词之后。

## 2. 「声音」页：31 段曲线可以拖了

原来调一个频段要在 31 根细滑块里找那一根，上面的折线只是结果预览、不跟手。现在折线本身就是控件：

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 改离指针最近的那一段，曲线实时跟随 |
| Shift + 拖动 | 把经过的频段一起涂改，中间不漏段 |
| 双击 | 那一段复位到 0 dB |
| 滚轮 | 在当前选中频段上 0.1 dB 微调 |
| ← → | 选频段 |
| ↑ ↓ | 步进 0.5 dB（Shift 为 0.1） |
| Delete | 选中段复位 |

- **跟手但不打满后端**：拖动中每 80 ms 生效一次，松手立即生效。
- **精确值还在**：31 根滑块保留在「精确调整」折叠区，需要逐段对数值时展开。
- **键盘可操作**：曲线是 `role="slider"` 的焦点元素，朗读文本给出当前频段与增益。

## 3. 实现

逻辑从界面里抽出来，因为「涂改时中间漏没漏段」「对数轴位置算错 1 px」这类错在界面上很难看出来：

- `ui/src/EqCurveEditor.vue`：指针、滚轮与键盘事件；拖动节流、松手提交。
- `ui/src/eqInteraction.ts`：横向比例 → 频段下标、纵向比例 → dB、涂抹区间、不可变写值。
- `ui/src/stageCurve.ts`：曲线几何（对数轴、0 dB 中线、路径与填充、峰值、显示格式），桌面曲线与状态栏共用。
- `ui/src/App.vue`：stage 页重排、`updateGains` 就地写回（保持 `s.gains` 引用不变，滑块与曲线读同一份数据）。

## 4. 验证

- 前端测试 `npm test --prefix ui`：**45 通过 / 0 失败**（0.9.5 时是 25 项，本轮新增 20 项：曲线几何 7 项、交互换算 4 项，其余为版本号落点与既有用例）。
- 前端构建 `npm run build --prefix ui`：通过（`vue-tsc --noEmit` + vite build）。
- Rust：见文末实测数字。
- iOS：本版 IPA 与 `ios-v0.9.8` 同一份构建（iOS 侧代码本版未改动），版本 0.9.8 / build 24。

## 5. 仍未闭合

- 拖动进度条时不显示这一段音频的波形，松手才跳（盲拖）。
- 曲库/队列还不能拖拽排序。
- 播放页没有键盘演奏式 A/B 旁路。
- 曲线只能涂改，还不能存成预设。
- iOS 侧曲线仍只支持单段拖动，多选频段与桌面端的 Shift 涂抹还没对齐。
- iOS XCTest 在本机仍跑不起来（模拟器 service hub 起不来），iOS 侧的验收还是「编译通过 + 独立 harness」，不等于 XCTest 通过。

## 安装

- **macOS**：解压 `Awake-0.9.8-macos-arm64.zip`，把 `Awake.app` 拖进「应用程序」。ad-hoc 签名，首次打开需在「系统设置 → 隐私与安全性」里允许。
- **iOS**：未签名 IPA，需自行重签（TrollStore / AltStore / Sideloadly 均可）。同一份 IPA 也在 iCloud Drive 里。

# Awake iOS 0.9.13

iOS 17+。这一版修三件「界面本该自己说清楚、却一直让用户自己扛」的事：玻璃皮肤在没有层次的背景上等于不存在；知道自己耳机型号的人进「声音」页仍要从空白输入框开始；mini player 和 tab 托盘互相咬。

## 之前的问题

- **玻璃看不出是玻璃**：背景是一整片平涂色，`glassEffect` 的折射没有东西可折，玻璃卡和实色卡并排几乎是同一张。玻璃需要的不是更强的模糊，是背景里本来就有层次。
- **知道自己型号的人没有捷径**：「声音」页四个起点解决了「不知道从哪开始」，但「按耳机型号套用」还压在曲线面板下方，点进去还要手打完整型号——等于每次从零开始。
- **mini player 压住托盘**：用 `safeAreaInset` 挂在 `TabView` 上，iOS 26 的浮动 tab bar 会盖住它，底部两行字互相咬。

## 现在

- **玻璃皮肤有了可折射的背景**：仅在 glass 皮肤下，背景改成纵向渐变（顶部 `#33373d` → 底部背景色）并加大半径的白色径向高光。light / dark 皮肤不动。截图时可用 `AWAKE_E2E_SKIN=glass|light|dark` 指定皮肤。
- **新增 `GlassRow` / `glassRows()`**：玻璃皮肤下把行背景换成 `ultraThinMaterial` + 0.5pt 高光边，非 glass 皮肤原样返回。（见下面「仍未闭合」——这条还没真正生效。）
- **「按耳机型号套用」上移到四张起点卡片之后**：有型号的人第一屏就能看到它，标题也从「查找社区测量 EQ」改成用户视角的说法。
- **进社区测量页自动带上型号**：一键把当前链路的耳机型号带过去，页面接受预填，不用再手打一遍。
- **mini player 交给系统排**：改用 `tabViewBottomAccessory`（iOS 26），由系统把它排在 tab 托盘上方；更早的系统退回 `safeAreaInset`。截图确认首页 mini player 与托盘上下分开。
- **首页去掉导航栏标题**：「awake.」那行标题拿掉，四张起点卡片直接顶到最上。

## 验证

- Release archive 通过：`Tools/build_ios_app.sh` 生成 `dist-ios/Awake-0.9.13.xcarchive` 与未签名 IPA。
- IPA：**1,682,894 字节**，SHA-256 `8260b38d4f040bdfb9f0053078390cca8c7a2b2e99babe910d0b934d43b33272`；`Info.plist` 为 `0.9.13` / build `29` / 最低 iOS 17.0；`unzip -t` 无错。
- 截图验证：iPhone 17 Pro / iOS 27 模拟器上，首页 mini player 与 tab 托盘不再互相遮盖。

**没有做到的**：iOS XCTest 在本机仍跑不起来（模拟器 service hub 起不来），验收口径还是「编译 + archive 通过 + 截图」。玻璃与起点卡片的实际观感、以及「按型号套用」查出来的曲线对不对，只能由你上手判断。

## 仍未闭合

- **`GlassRow` 目前没生效**：挂在 `Form` 上，`listRowBackground` 不向下传递到行，截图里设置页行背景仍是不透明的；要改挂到每个 `Section` 上。这一条明写着「待验证」，本轮没修，所以设置 / 曲库 / 评测的容器级玻璃也还没做完。
- 起点仍只有四种，还没有「按型号一键写进当前链路」的自动路径——现在只是把型号带过去查。
- 桌面端 0.9.12 的黑白配色、玻璃层与插件源入口还没有出包；本轮只出 iOS。

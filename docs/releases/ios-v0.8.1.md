# Awake iOS 0.8.1

iOS 17+，未签名 IPA，需自行重签。0.8.1 的目标不是再加一个旁路功能，而是把 0.8.0 遗留的移动端 / 桌面端差距补齐；之后桌面端的功能与交互变更默认同版本迁移到 iOS，不再单方面缩小范围。

## Plex 对齐

- 账号授权后列出服务器的全部可用线路（本地 / 远程 / 中继，HTTP / HTTPS），而不是只取一条。
- 选中线路后先探测 `/identity`，再读取音乐库分区；可选择具体音乐库，扫描只取该分区，分区失效会明确报错。
- 修复授权 URL 里 `context` 参数拼接错误；服务器列表缺少 `provides` 标注时有兜底解析。

## 歌单对齐

- 导入歌单时，未匹配曲目不再被丢弃：可以勾选并保存为「待匹配曲目」，歌单行显示待匹配数量。
- 歌单改为详情页：匹配曲目、待匹配曲目分区展示；进入详情页与点击「重新匹配」时按歌名/艺人自动匹配，匹配后写入歌单。
- 待匹配条目随 `playlist.json` 持久化，旧歌单兼容。

## 听书与 AI 拆书对齐

- 没有专辑标签的音频按导入文件夹归并成书；章节按轨号、CUE 分段与标题自然排序。
- AI 拆书 / 拆剧不只直接朗读：新增「生成有声书」，用系统语音合成 PCM、导出 AAC m4a（失败时保留 CAF），写入本机曲库并生成同名歌单，和桌面端一样进入听书书架、支持续听。
- 已配置策展服务时可勾选云端 AI 分章；失败自动回退本地分章并说明。
- 保留直接朗读预览与多角色语音。

## 新闻对齐

- 公开链接、粘贴文本、.eml 邮件导入保持不变。
- 新增云端 AI 摘要开关；失败自动回退本地摘要。导入的播客音频仍可直接进入曲库。

## 本周总结对齐

- 增加新增曲目、收藏数、艺人时长榜；保留每日柱状图、最常播放与可解释文字。

## 验证

- 单元测试：65 项执行、4 项跳过（外部连接器/网络夹具）、0 失败。新增覆盖：多线路 Plex 解析、文件夹归并、待匹配持久化、真实语音合成并读取 m4a/CAF。
- UI 测试：首页 → 听书与播报 → 书架 / AI 拆书 → 本周总结。
- 未签名 IPA 0.8.1 (17) 构建通过并安装到模拟器。

## 平台固有差异（非功能缺失）

- iOS 文件导入会复制进沙盒；桌面可以原地引用文件路径。两者都能导入本地文件，但存储方式不同。
- iOS 使用系统语音音色；桌面使用 macOS say 音色，听感不同但都支持分章与多角色。
- 真机锁屏长时朗读、真实 Plex 账号与复杂邮件仍需对应环境验收。

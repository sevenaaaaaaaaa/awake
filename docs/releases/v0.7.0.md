# Awake 0.7.0

macOS 14+（Apple 芯片）本地播放器，Rust / Tauri 2 / Vue 3 主线。本页为 GitHub Releases 的桌面版说明；安装包为 ad-hoc 签名，首次打开可能需要在“隐私与安全性”中允许。

## 刷音乐

- 底部播放条有当前曲目时出现「刷音乐」入口，打开覆盖整个窗口的聆听层，不是新的主页面。
- **上下模式**：滚轮、↑↓ 或上下拖动切换上一首/下一首，首尾环绕。
- **卡片模式**：卡片叠放，指针拖动右滑「喜欢」（收藏并下一首），左滑「跳过」，上下拖换歌；拖动时显示对应标记。
- 显示封面、曲名/艺人/专辑、进度、暂停与收藏；Esc 或右上角关闭退出；尊重系统「减少动态效果」。
- 队列使用当前播放队列，否则使用整个曲库，切歌连续。

## 歌单导入

入口在侧栏「我的歌单」右侧。流程是**只取歌单元数据 → 与本地曲库匹配 → 生成歌单**，不下载或播放平台版权音频。

- **网易云音乐**：`/api/v6/playlist/detail` 取全量 `trackIds`，再分批 `/api/song/detail` 补全（实测 305 首歌单全量）。
- **QQ 音乐**：公开歌单接口（需要 Referer；隐私歌单会明确提示 subcode 4000，不存在提示 code 10）。
- **YouTube**：`www.youtube.com` 页面 + 新版 `lockupViewModel`，续页参数递归查找后翻页（实测 100 + 47 = 147 首）。
- **Apple Music**：公开歌单页的 `serialized-server-data`，读取 `trackLockup` 曲目；地区重定向会给出明确提示。
- **Spotify**：公开嵌入页，最多 100 首；该主机可能限流，失败时提示改用粘贴文本。
- **粘贴文本**：每行「艺人 - 歌名」，适合任何平台复制或导出后的内容。
- **文件**：M3U / M3U8 / PLS / CSV / TSV / JSON / TXT，以及 **CUE** 解析。
- 匹配按标题、艺人、时长打分（高置信 / 较可能 / 低置信），可「只看未匹配」，未匹配条目可在曲库中手动指定，再创建静态歌单；不会自动扫描或自动播放。

## CUE 支持的边界

- 已解析 `FILE` / `TRACK` / `TITLE` / `PERFORMER` / `INDEX 01 mm:ss:ff`（75 帧/秒）并保留分轨起止时间。
- **桌面 0.7.0 暂不支持 CUE 分轨播放**：整轨需已在曲库中，播放的是整轨；分轨播放会放在下一版本。iOS 0.7.7 已支持整轨虚拟分轨播放。
- APE（Monkey's Audio）在任何平台都无法直接解码，需先转 FLAC / ALAC；MP3 / AAC 的分轨有帧级误差。

## 验证

- 离线：`awake-app` 51 项通过（10 项在线/声卡测试默认忽略），`awake-core` 37 项通过；前端 `npm run build`（vue-tsc + vite）通过。
- 在线（单独运行，`--ignored`）：5 个平台真实歌单全部通过——网易云 305 首、QQ 76 首、YouTube 147 首（续页生效）、Apple Music 74 首、Spotify 50 首。
- 桌面包由 `Tools/build_rust_app.sh` 构建并 ad-hoc 签名，`codesign --verify --deep --strict` 通过；启动后写入 `frontend_ready.txt` 作为 WebView 挂载证据。
- 界面在 1440px / 1100px / 390px 宽度下检查；刷音乐与导入完成流程使用浏览器预览回归（桌面 Tauri 端到端仍需在真实曲库中复验）。

## 限制

- 平台公开页面与接口可能改版或限流；Spotify 只有前 100 首；所有平台公开数据都没有 ISRC。
- 私密/地区受限歌单需先公开或改用粘贴文本。
- 未用真实用户的大体量歌单、真实限流或失效链接验收；Apple Music 的专辑字段可能等于单曲名。
- 不重命名磁盘文件、不回写音频标签。

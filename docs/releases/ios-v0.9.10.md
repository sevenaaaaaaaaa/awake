# Awake iOS 0.9.10

iOS 17+。这一版不动功能，只动「看起来是谁」：**图标重画、颜色收到只有黑白两色、首页与曲库的入口重排。**

上一版（0.9.9）修的是播放页出不来；这一版是设计方向第一次落地。

## 1. 图标：把耳朵画成听觉系统

原来的图标是深蓝紫渐变底 + 日出/声波符号——和任何一个音频 App 都能互换。新的只有一个东西：**听觉系统本身**。

- **一条从外向内的螺旋**：耳蜗的形状。它不是装饰，是听觉器官最可辨认的轮廓。
- **中心一枚实心点**：声音落到的地方。
- **开口处三段越来越淡的弧**：声音正在进来（或者正在离开）的那一下——「唤醒」发生在这里。

只有两个元素：一条线、一个点。没有渐变、没有光斑、没有字母，黑白两色。几何全部来自 [Tools/make_awake_icon.swift](Tools/make_awake_icon.swift) 一次绘制，同时产出 macOS 的 `.icns` 与 iOS 的 AppIcon，不靠手工缩图。

## 2. 颜色：从「蓝」到只有黑白

- 三个皮肤（黑 / 白 / 玻璃）走同一条中性阶，**强调色就是白或黑**；按钮是白底黑字，没有第二个色相。
- **老档案会迁移**：`library.json` 里存的是上一版的蓝，直接读出来会把新配色挡在门外。现在读盘时按皮肤 id 换成当前调色板（version 2），**自定义皮肤一个字不动**。迁移只在读盘发生一次，写回后就是 2。
- 顺带修掉一个自己踩的坑：皮肤 `validate()` 原来只认 `version == 1`，迁移后第二次启动会把档案判成损坏。现在接受 `1...2`。

## 3. 液态玻璃

- `GlassSurface`：iOS 26 起用系统 `glassEffect`（折射、边缘高光、实时模糊都由系统渲染），更早的系统退回材质 + 一道 0.5pt 结构线——只有模糊没有边，卡片会糊进背景，读不出「这是一块」。
- 用在**浮在内容上的东西**：卡片面板、常驻 mini player。页面级背景不用玻璃，否则整页会糊成一片，层级反而没了。
- 播放页补了 `tint`：cover 不继承 TabView 的着色，上一版的黑白会被系统蓝破掉（上一首/下一首、随机、收藏都是蓝的）。

## 4. 入口：首页与曲库

- **首页**：去掉 `YOUR LISTENING SPACE` 大写宽字距标签与 36pt 双行口号。首屏只回答一个问题——有在听的歌就是「接着听」（点开播放页），没有就是「开始我的电台」。四个入口从 2×2 等权胶囊改成一张面板四行：图标 + 标题 + 副标题 + chevron，副标题写「进去以后做什么」。
- **曲库空状态**：原来只有一句说明，没有按钮。现在三个动作摆在页面上——从文件导入（主）、导入一个文件夹、连接 NAS / WebDAV / Plex；筛选到空来源时给「看全部来源」与「到设置刷新来源」。
- **mini player**：从每个 tab 的底部插槽挪到 TabView 一层。原来它被 iOS 26 的浮动 tab bar 压住，只剩一条模糊的影子。

## 验证

模拟器（iPhone 17 Pro / iOS 27）逐屏实跑截图：首页、播放页（黑白曲线与按钮）、播放页关闭后、空曲库、恢复后的曲库。空曲库是把 `library.json` 备份—删除—冷启动—截屏—恢复得到的，恢复后 3 首曲目回到列表。

**没有做到的**：iOS XCTest 在本机仍跑不起来（模拟器 service hub 起不来），所以这一版没有 XCTest 结果；验收口径是「Debug 构建通过 + Release archive 通过 + 模拟器逐屏截图」。

## 仍未闭合

- 设置页与声音页的入口还没重排（设置是一长串分组、来源藏在二级页；声音页缺「我该从哪开始」）。
- 玻璃还没铺到设置/曲库/评测页的容器。
- 桌面端（Tauri/Vue）仍是旧配色与旧图标。
- 播放页曲线仍只支持单段拖动，多选频段还没和桌面端对齐。

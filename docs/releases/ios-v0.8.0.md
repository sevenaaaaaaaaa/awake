# Awake iOS 0.8.0

iOS 17+，未签名 IPA，需自行重签安装。本轮把桌面 0.8 的听书、AI 拆书 / 拆剧、新闻播报、本周总结与「为你生成」迁移到 iPhone / iPad。

## 听书模式

- 新增「听书与播报」入口（首页与曲库工具栏）。按专辑或书名归并曲库里的长音频；没有专辑标签时，只把明确像有声书的长音频识别为书。
- 章节按标题自然排序（第 2 章排在第 10 章之前）；书架显示章节数、总时长与完成度。
- 「继续听」从上次章节与位置接着播放；每 15 秒、暂停与切到后台时保存进度，重启后保留。
- CUE 分轨章节沿用现有 segmentStart 排序。

## AI 拆书 / 拆剧

- 粘贴正文或导入 .txt / .md，选择「拆书」或「拆剧」，先预览分章，再开始朗读。
- 拆书按「第 X 章 / Chapter N / Markdown 标题」分章；拆剧识别「角色：台词」并为不同角色分配不同系统语音与音高。
- iOS 首版使用 AVSpeechSynthesizer 直接朗读章节（支持暂停 / 继续 / 停止 / 再听一次），不导出音频文件；文本不会上传，分章在本机完成。
- 最近拆分保存在本机，可再次朗读或删除。

## 新闻与邮件播报

- 支持公开链接、粘贴文本、导入 .eml 邮件（纯文本 / base64）；只读取用户给出的内容，不登录邮箱。
- 本地摘要后生成一段 AI 新闻播报，用系统语音朗读；也支持直接导入播客音频到曲库。
- 新闻条目保存在本机，可删除。

## 本周总结

- 首页新增入口：本周聆听时长、完整播放、不同艺人、进行中的书、每日柱状图与最常播放的五首。
- 统计只读取本机收听记录，不上传；时间范围为本周一到今天。

## 为你生成

- 曲库顶部固定「为你生成」动态歌单，按收藏、完整播放与最近聆听重新排序；首页也提供直接播放入口。

## 未迁移 / 边界

- 桌面端的 Plex 多线路探测、本地文件清单来源、歌单「待匹配条目」持久化仍以 macOS 为准；iOS 继续使用现有文件导入与手动匹配。
- iOS 的 AI 朗读不是离线音频文件生成，不能导出有声书文件；桌面端仍可导出 m4a。
- 真实长篇小说朗读时长、锁屏后台播放与不同系统语音的听感需真机验收。

- UI 测试：首页 → 听书与播报（书架 / AI 拆书）→ 本周总结，导航与关键控件存在性通过。
- 未签名真机 IPA 构建通过，Info.plist 为 0.8.0 (16)；已安装到 iPhone 17 Pro 模拟器并启动，首页与新增页面可打开。

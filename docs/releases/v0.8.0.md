# Awake 0.8.0

macOS 14+（Apple 芯片）本地播放器，Rust / Tauri 2 / Vue 3 主线。安装包为 ad-hoc 签名，首次打开可能需要在“隐私与安全性”中允许。

## 修复

- **Plex 授权后没有来源**：账号授权后会列出服务器的全部可用线路（本地 / 远程 / 中继，HTTP / HTTPS），逐条探测是否可达，再按所选音乐库连接；连接成功后提示实际曲目数并立即出现在「音乐来源」。分区选择会真正限定扫描范围，不再只是改名字。连不上时会明确提示换一条线路。
- **本地文件夹与本地文件无法导入**：新增原生「选择文件夹」「选择音频文件（可多选）」；支持把文件夹或文件直接拖进窗口；扫描过程显示完成数 / 总数；导入结果提示成功与跳过数量。逐个导入的文件会记录为「本地文件」来源（原地读取，不复制、不移动）。
- **歌单解析后无法导入、没有地方查看**：解析出的未匹配曲目不再被丢弃，会保存为待匹配条目并保留歌名 / 艺人 / 专辑；歌单页新增「待匹配曲目」区域，曲库更新后自动重新匹配；导入时可一键保存整份歌单（含未匹配）。

## 听书模式

- 侧栏新增「听书与播报」。按书归并本地 / WebDAV / Plex / Telegram 中的长音频：优先用专辑标签，没有标签时按文件夹归并（文件夹名带任务 UUID 时会自动去掉）；章节按碟号、轨号与文件名自然排序（第 2 章排在第 10 章之前）。
- 书架显示封面、作者、章节数、总时长与完成度；支持按最近在听 / 书名 / 作者 / 未听完排序；「继续听」从上次章节与位置接着播放，进度每 15 秒与暂停 / 播完时写入本地档案。
- 可切换「全部长音频」查看所有专辑级长内容；m4b / aa 等有声书格式会优先识别。

## AI 拆书与拆剧

- 粘贴正文或导入 .txt / .md，选择「拆书」或「拆剧」，先预览分章，再合成音频。
- 拆书：按「第 X 章 / Chapter N / Markdown 标题」分章，长章自动续分；每章用系统语音合成可播放音频。
- 拆剧：识别「角色：台词」格式，旁白与角色分配不同中文语音，分段合成后拼接为单章音频。
- 合成使用 macOS 内置 say 与 afconvert，完全离线、不产生费用；已配置云端策展服务并可勾选时，可让 AI 智能分章（会明确提示发送本次文本）。
- 合成完成后自动生成「本地」来源与同名歌单，直接进入书架与播放器；后台任务显示章节进度与错误。

## 新闻与邮件播报

- 「新闻播报」支持公开链接、粘贴文本、导入 .eml 邮件（支持 text/plain、base64、quoted-printable）；只读取用户给出的内容，不登录邮箱。
- 勾选条目后一键生成 AI 新闻播报：本地摘要或已配置的云端 AI 摘要，再合成整段音频并加入歌单。
- 播客音频可直接用「导入播客音频」加入本地文件来源。

## 本周总结

- 新增「本周总结」页面与首页卡片：本周聆听时长、完整播放、不同艺人、新增曲目、每日柱状图、最常播放的五首与时长最多的艺人，并给出可解释的中文总结。
- 统计仅来自本机收听记录，不上传。

## 推荐歌单

- 「我的歌单」顶部固定「为你生成」：每天按最近聆听、完整播放、跳过与收藏重新排序，打开即听。
- 首页新增「推荐歌单」：为你生成、专注时刻、偶遇新频率；后两者按需创建为动态歌单。

## 数据格式

- 歌单新增可选的待匹配条目（entries），旧歌单与 iOS 数据保持兼容；曲库来源新增 Plex 分区与本地文件清单字段，均带默认值。
- 新增数据：books/plans（拆分任务）、books/library（合成音频）、news.json（新闻条目）。

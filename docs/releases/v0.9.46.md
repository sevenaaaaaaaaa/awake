# 0.9.46

> 版本号 0.9.46（桌面与 iOS 同一号），iOS build 58。
> 这一版落地「耳形」：打开应用不再进入一个播放器的首页，而是进入你的耳朵。
> 方向经三轮原型确认（`.build/ear-shell/`，v2 整屏方案获用户拍板），本轮接上真实数据。

## 你能看到的

**启动即耳朵。** 整屏没有侧栏、没有播放条：31 段 EQ 画成一条耳蜗螺旋（内圈低频、外圈高频，
与耳蜗基底膜的真实排布同构），它此刻的形状就是这首歌为你做的适配。歌名与一句话结论在耳心，
进度是外圈的轨道环，接下来的曲目是轨道上的节点（带一句为什么给你）。

四个动作直接长在耳朵上：

- **听**：空格播放；耳形随音乐轻微呼吸；
- **比**：按住耳朵（或 B 键），整条曲线松开成基线——「原样」，右下角写「EQ 旁路 · 平直输出」；
  松手回来后会问「哪一个是你要的？」，**点形状作答**（这一票先记录、暂不写先验，见「还没做的」）；
- **说**：点耳心，四个词环绕（更亮 / 人声 / 收紧 / 太吵），或直接打一句——走已有的
  `suggest_curve`，agent 只动曲线，结果自动应用并以一句话回显；
- **查**：悬停任意一段，当场说出那段在做什么、凭什么（这首歌的记忆 / 链路曲线 / 手动曲线）。

拖动耳朵任何一段可以直接捏那条曲线（80ms 节流真写后端，与曲线编辑器同一管线）。

**耳朵会睡。** 没有曲目时整只耳朵变暗、缓慢起伏，中心写着「耳朵在睡。放一首，唤醒它」。
打开应用时螺旋从中心自己长出来。

**旧的界面都还在。** `L` 键（或从耳形按 ⌘L）回到「为你而鸣」列表视图，偏好会记住；
侧栏第一项就是「耳形」，随时回去。曲线编辑器、「此刻」仪器页、B 键旁路全部不变。

## 实现

- `ui/src/earShape.ts`：耳蜗几何（对数展开、Catmull-Rom 平滑、命中检测、峰谷提取），9 项单测；
- `ui/src/EarView.vue`：整屏组件，接真实状态——`s.gains`（曲线）、`s.playback`（进度）、
  `s.queue`（节点）、`s.curveInfo`（依据）、旁路与调音的既有管线；颜色全部走皮肤令牌；
- `ui/src/App.vue`：`ear` 成为第一屏（默认开，`awake.earHome` 记偏好），旁路放行给耳形，
  一句话调音在耳形里自动应用；
- 数据边界（如实）：听辨投票尚未写进先验，这首歌的历史调法（旧纹路）尚未显示——两者都要
  先有数据层，排下一批。

# 0.9.49

> 版本号 0.9.49（桌面与 iOS 同一号），iOS build 61。
> 上一批候选三条全部落地：听辨有落点、调音史看得见、搭子进了耳朵。

## 听辨投票有了落点：真正改「这首歌的适配」

按住松手后的「点形状作答」不再是空回应——

- **「适配更好」**：把当前曲线连同三段依据写成这首歌的记忆（`remember_song_curve`），
  下次放这首歌就照这条；
- **「原样更好」**：这首歌退回链路曲线（`forget_song_curve`）；本来就没有单独记忆时
  如实说「原样就是链路」，不假装改了什么；
- 边界如实说明：**全局个人先验没有桌面写入口**，这一版动的是这首歌的记忆，不动先验文件——
  先验的桌面写入要等与 iOS 同构的数据层，排下一批。

## 旧纹路：这首歌被换掉的调法，细线留在螺旋上

- 每次换调法（预设 / 一句话调音 / 记住 / 拍板）之前，当前形状自动存为一条**旧纹路**：
  螺旋上一根淡细线，最多三条，换歌即清空；
- 点细线（或声音层「旧纹路」里的按钮）＝**套用当时的样子**，当前的形状自动存回去，可来回比；
- 按住仍是听「原样」（真旁路），与旧纹路互不干扰；
- 边界如实说明：旧纹路是**界面层的本次会话记录**，不是后端持久化的调音史——落库需要
  后端先有历史 schema，也是下一批的事。

## 搭子进了耳朵

右上角新增「搭子选曲」：点了就地选（本地兜底离线可用；配置了云服务走云策展），
选完外圈轨道上的节点换成搭子挑的曲目，每个节点带一句**为什么给你**（推荐理由），
点节点直接放。选曲期间按钮显示「搭子在选…」。

## 细节

- 声音层开着时，右上角两个按钮隐藏（层内已有等价入口，不再被层盖住）；
- 「记住这首歌 / 忘掉这条」也会留一条旧纹路，忘错了可以点回来。

# Awake 0.7.1

macOS 14+（Apple 芯片）本地播放器，Rust / Tauri 2 / Vue 3 主线。安装包为 ad-hoc 签名，首次打开可能需要在“隐私与安全性”中允许。

## 手机 → 电脑播放接力

- 手机正在播放时，「接力到电脑」把曲目和当下进度交给同一 Wi-Fi 下的电脑继续播放。
- 电脑在底部播放条的盾牌入口里打开「数据与接力 → 手机接力」，点「接收接力」后显示 6 位配对码；手机自动发现附近电脑（或手动填 IP:端口），输入配对码发送。
- 电脑按曲名/艺人/专辑/时长匹配本地曲目，命中后沿用当前音量与 EQ，并 seek 到手机上的进度；未命中会提示“电脑曲库没有找到这首歌”。
- 配对码 10 分钟无请求过期、错 5 次自动换码、每 2 秒最多 1 个请求；只传曲目元数据与进度，不传音频、账号或 Token。
- 仅局域网、手机 → 电脑单向；电脑端停止接收即关闭端口与 mDNS 注册。

## 端到端加密备份与恢复

- 电脑：盾牌入口 →「加密备份」；手机：设置 →「备份与恢复」。
- 密码经 PBKDF2-HMAC-SHA256（310,000 次）派生 256 位密钥，AES-256-GCM 加密；文件里只有必要的 kdf/salt/密文，导出时间与设备名在密文内。密码不会保存，服务端不存在。
- 备份内容：曲库元数据、歌单、收藏、评分与偏好配置、皮肤/聆听链路等设置，以及上次播放的曲目与进度。
- **不含**音频文件，也**不含**钥匙串中的密码/API 密钥/Token——恢复后需重新填写。
- 桌面导出直接写入 下载目录 的 awake-backup-<时间>.awake-backup（若失败可复制备份文本自行保存）；恢复先预览设备/时间/曲目/歌单/收藏，再确认。
- 恢复前自动写安全副本（data_dir/backups/restore-<时间>/）；只接受本平台备份，跨平台会明确提示（跨平台只支持歌单导入）。
- iOS 恢复后显示“上次播放（m:ss）”，可点「继续播放」在匹配曲目上 seek，不自动播放。

## 验证

- Rust：awake-app 64 项、awake-core 37 项通过（新增 13 项：备份固定向量逐字节一致、roundtrip、错误密码/篡改、跨平台 schema 拒绝、安全副本与回滚、接力匹配、配对码限流/过期状态机、本地 HTTP 冒烟）。
- iOS：64 项测试通过（新增备份 7 项与接力 11 项，含固定向量、错误密码、schema 拒绝、接力请求/响应/地址解析与发送契约）。
- 桌面 0.7.1 构建、codesign --verify --deep --strict 与启动冒烟（frontend_ready version=0.7.1）通过；zip 解压后签名校验通过。
- iOS 0.7.8 未签名 IPA 构建通过（需自行重签）。

## 未验证

- 真实两台设备（iPhone + Mac）的 mDNS 发现与 HTTP 往返、真实扬声器上的 seek 落点；电脑端接收器需要在真实 App 内点开验证。
- 真实用户曲库上的“导出 → 换设备 → 恢复”完整流程（单测覆盖格式与临时目录；UI 恢复需手动点一次）。
- 桌面下载目录在个别 WKWebView 环境下的行为（已改为 Rust 直接写下载目录作为主路径，并保留文本复制兜底）。
- CUE 分轨播放在桌面仍未支持（0.7.0 起）；APE 需转 FLAC/ALAC。

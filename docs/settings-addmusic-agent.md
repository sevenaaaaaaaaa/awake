# 设置、源导入、agent 模式：三处体验的改造

这一版只动 iOS 的三个面：设置页、添加音乐（源导入）、调音 agent 与听歌搭子的模式。

## 一、设置：先给状态，再给入口

**问题**：第一屏就是九个分区、二十多行入口，看得到按钮，看不到「我现在是什么状态」。
来源行、内置示例、清理动作混在一起，破坏性操作和日常入口同一屏。

**改法**

- **顶部摘要卡**（现算，不是写死的）：版本与 build、曲目 / 歌单 / 来源 / 缓存四个数字、
  当前皮肤名、AI 是否已配置（未配置时明说「走本地规则」）。
  缓存大小在后台枚举 `Music/` 求和，算完再显示，不阻塞首屏。
- **入口改成两行式**（`SettingsEntry`）：标题 + 一句「点进去会看到什么」+ 右侧真实状态
  （曲线条数、校准版本、调音记录数、AI 模型名、来源数量）。裸 `Label` 不再出现。
- **来源行重做**：图标 + 名称 + 类型与曲数，刷新 / 移除收进一个 44pt 的菜单，
  不再用两个并排的文字按钮占掉整行。
- **两个维护分组合并**成一个「曲库维护」：整理曲库、补齐内置示例、移除内置示例、
  清空本地添加的记录；说明文字写清各自的边界（哪些会删文件、哪些保留来源配置）。

## 二、源导入：三种服务器各自的「需要准备什么」

**问题**：以前「从服务器」只有一个按钮，进去再在下拉框里选类型；选完才看到要求
（Plex 要登录、Telegram 要先跑连接器），失败一次才知道。

**改法**

- **已连接**分区：每个来源一行，图标 + 名称 + 类型与曲数；管理动作回到设置，避免两处都能改。
- **三种服务器各一行**，副标题直接写要求：
  - WebDAV / NAS / 网盘：「需要服务器地址、账号与应用密码」
  - Plex：「用 Plex 账号登录换 Token，或直接填 Token」
  - Telegram：「需要先在自己电脑上跑连接器」
  点哪一行就带着类型进 `SourceEditor(initialKind:)`，不用再选一次。
- **从本机**三行保留，副标题写清格式与「App 自己的缓存目录不会被当成来源」。
- 「最近一次导入」直接显示 `store.message`，导入完回到这页能看到结果。

## 三、agent 模式：同一句话，五种取舍

**问题**：调音 agent 只有一套提示词，候选之间只有「保守 / 更彻底」的差别；
没配 AI 时更是只有固定短语映射，看起来像一个按钮而不是一个 agent。

**改法**

- 新增 `TuningMode`（5 个），每个模式同时带 **AI 约束** 与 **本地规则动作**：
  | 模式 | 取向 | 本地动作（没配 AI 时也真实生效） |
  | --- | --- | --- |
  | 均衡 | 只处理你说的，其余不动 | 关键词规则，不加取向 |
  | 人声 | 1.6–3.2k 靠前、齿音不刺 | +1 dB 人声段、6.3–8k −0.8 dB |
  | 耐听暖声 | 长时间听不累 | 6.3–12.5k −1.5 dB、100–200 Hz +1 dB |
  | 现场感 | 空间与冲击，别糊 | 8–12.5k +1.5、80–160 Hz +2、400–630 Hz −0.8 |
  | 夜间低音量 | 小音量等响补偿 | 50–120 Hz +2.5、10–12.5k +1.5、1–2k −1 |
- 所有模式共用同一套安全阀：单段 ≤6 dB、最多 6 段、整体不抬响度（`clamp`）。
- 调音面板把模式做成竖排列表（名称 + 取向 + 勾选），一屏看全；候选标题写明来源，例如
  「AI · 夜间低音量」「本地规则 · 耐听暖声」，不冒充。
- 听歌搭子新增 4 个**策展模式**（此刻 / 通勤 / 专注 / 深夜）：只改发给 AI 的意图与模式名；
  本地排序仍按收藏与有效收听，界面明说「本地排序不区分场景」。

## 实现

| 文件 | 作用 |
| --- | --- |
| `ios/Awake/SettingsViews.swift` | 摘要卡、`SettingsEntry`、来源行菜单、维护分区合并、`SourceEditor(initialKind:)` |
| `ios/Awake/AddMusicView.swift` | 源导入 hub：已连接、三种服务器、本机导入、最近一次导入 |
| `ios/Awake/SoundTuning.swift` | `TuningMode` / `TuningModes`、按模式的本地规则、AI 提示词带模式 |
| `ios/Awake/TuneSheet.swift` | 竖排模式选择、结果来源标注 |
| `ios/Awake/LabViews.swift` | `CurateMode` 与听歌搭子的模式条 |
| `ios/AwakeTests/AwakeTests.swift` | 模式唯一性、同句不同曲线、限幅与改段数、空输入不改曲线 |
